# FFmpeg Workbench v0.2.0 Preview

首个跨平台安装包预览版，将常用 FFmpeg 操作整理成中文功能和图形配置，素材在本机处理。

## 下载与安装

- **macOS 11 及以上**：下载 `FFmpeg-Workbench_0.2.0_macOS-universal.dmg`，兼容 Apple Silicon 与 Intel。打开镜像，将应用拖入“应用程序”。
- **Windows 10 / 11 64 位**：下载 `FFmpeg-Workbench_0.2.0_Windows-x64-setup.exe`，按向导为当前用户安装。若缺少 WebView2，安装器会联网下载运行时。
- `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。

本预览版尚无正式发行签名：macOS 使用临时签名，未完成 Apple 公证；Windows 安装器未做发行者签名，系统可能提示无法验证开发者或发行者。受管理设备可能不允许安装此类预览包。

**安装包不附带 FFmpeg。** 首次打开后，在左下角“处理引擎设置”中选择本机的 FFmpeg 可执行文件。选择一个功能、添加素材、选择可写保存位置，即可开始处理。内置 5 秒示例可用于检查视频处理流程，示例没有声音。

## 本版功能

- 压缩视频、转换格式、截取片段、调整画面、提取音频、去除声音六个入口。
- 19 个常用控件、28 项低频图形配置，以及配置检查与兼容提示。
- 本机引擎连接、工程保存与载入、撤销、串行队列、取消和任务日志。
- 准备、处理、保存、完成阶段进度，显示已用时间、预计剩余、速度、帧数、结果大小。
- 完成后可直接预览视频或试听音频，支持暂停、拖动进度、音量、静音，以及打开所在文件夹。
- 修复 Windows 本地文件规范路径被误判为网络路径，以及结果文件定位的路径兼容问题。

## 发布验证与边界

发布工作流分别在 macOS 与 Windows 原生环境运行前端测试、原生测试和安装包构建；只有两个平台检查全部通过后才发布。macOS 镜像检查包括版本、双架构和临时签名；Windows 检查包括静默安装、程序启动存活和卸载。

macOS Apple Silicon 已有原生界面处理验证。Windows 和 Intel Mac 尚未完成同等范围的人工界面验收；CI 安装与启动检查不能替代全部功能实机测试。此版本仍为预览版，当前功能化流程支持一个素材和一个本地输出，并未覆盖 FFmpeg 的全部命令及参数。

内置播放能力取决于系统支持的格式和编码；部分输出需要使用外部播放器。任务队列仅在本次会话保留，关闭应用会取消活动任务。
